# Fracture-and-Implant-Localization-in-Wrist-X-rays-Using-Deep-Learning-Approaches
This project implements a hybrid deep-learning pipeline for fracture and implant localization in wrist X-rays using GAN-based image inpainting and YOLOv8 detection. The GAN reconstructs healthy bone structures and highlights abnormalities via reconstruction error which wasnt successful, while YOLOv8 provides precise fracture and implant bounding-box detection. The system includes a custom preprocessing workflow and a Streamlit interface for real-time inference. A detailed technical report, explaining the methodology, architecture, preprocessing steps, and experimental results, is also included in this repository for deeper insights.
